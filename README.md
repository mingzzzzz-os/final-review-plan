# 期末复习计划

六级（12/12）+ 六门期末课的日程表，手机上打开就能看，不用开电脑。

## 直接访问

- 在线版（WorkBuddy 托管）：见对话里的链接
- GitHub Pages：`https://mingzzzzz-os.github.io/final-review-plan/`

## 文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | 页面结构，三个标签页：今天 / 全程 / 科目 |
| `data.js` | **所有计划内容都在这里**，改日期、改任务只动这一个文件 |
| `app.js` | 逻辑：算倒计时、生成今日任务、勾选打卡 |
| `style.css` | 样式，移动端优先 |

## 怎么改

### 改考试日期

打开 `data.js`，最上面：

```js
const CONFIG = {
  cet6:  "2026-12-12T15:00:00",   // 六级（官方已定，不用改）
  finalStart: "2027-01-05",       // 期末首日，改成教务通知的日期
  finalEnd:   "2027-01-10",
};
```

再往下找到 `EXAMS`，把六天的「待定」换成真实科目：

```js
const EXAMS = [
  { date:"2027-01-05", subject:"材料物理化学", note:"上午 9:00" },
  ...
];
```

### 改每天的安排

- 阶段 A（11/17–12/11）的六级任务：`CET6_WEEKDAY` / `CET6_WEEKEND`
- 期末铺底轮转：`FOUNDATION`
- 12/13 之后的科目块：`BLOCKS`

### 加了新的一天 / 调整阶段边界

改 `PHASES` 里的 `from` / `to` 就行，倒计时和「今天该做什么」会自动重算。

## 打卡记录存在哪

浏览器本地（localStorage），按日期存。换手机或清缓存会丢，重要进度建议每周在纸上记一次。

## 部署到 GitHub Pages（如果还没开）

Settings → Pages → Source 选 `Deploy from a branch` → Branch 选 `main` / `root` → Save。
等一分钟，访问 `https://mingzzzzz-os.github.io/final-review-plan/`。

## 设计上的几个取舍

1. **两段式**：12/12 前六级为主、期末只铺底；12/13 后六级彻底放下。原因是六门课从零开始压在 3 周里，必须提前铺一层。
2. **每天一个主任务**：勾选框只服务当天，完不成不补，第二天照常。
3. **一页纸**：每科复习完必须留下手写的框架页，没有这页等于没复习。
4. **模拟考放在周日下午 15:00**：和真实考试同时段，让身体记住这个时间要清醒。
